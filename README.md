# IDARSI Ansible Role Development Guide

This repository contains public guidance for developing and testing reusable,
maintainable Ansible roles.

- [Ansible Role Development Guide](ansible-role-development-guide.md) covers
  role design and implementation conventions.
- [Ansible Role Testing Guide](ansible-role-testing-guide.md) covers
  automated test design, coverage, version matrices, and CI lanes.

The guide is intended to be referenced by role repositories through their
`CONTRIBUTING.md` files. Role-specific instructions remain in each role's own
repository.
